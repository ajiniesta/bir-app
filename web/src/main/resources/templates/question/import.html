    Formato del fichero

    El fichero puede contener varios objetos JSON seguidos (o un array). Cada pregunta necesita text, exam_type (id numérico o código, por ejemplo 3 o BIR) y answers con exactamente una respuesta correcta. Las letras válidas son A, B, C y D. category, tag y explanation son opcionales. Las comas finales están permitidas. Las preguntas con errores se descartan y el resto se importa. Las que ya existen en el mismo banco (mismo enunciado) se omiten, así que puedes repetir una importación interrumpida sin crear duplicados. 

    {
  "exam_type": "3",
  "category": "Fisiología",
  "tag": "Tema 1",
  "text": "Esta es la pregunta",
  "explanation": "Esta es la explicación",
  "answers": [
    {"letter": "A", "text": "respuesta 1", "is_correct": true},
    {"letter": "B", "text": "respuesta 2", "is_correct": false},
    {"letter": "C", "text": "respuesta 3", "is_correct": false},
    {"letter": "D", "text": "respuesta 4", "is_correct": false}
  ]
}
